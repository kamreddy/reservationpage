Restaurant Reservation System

This HTML document represents a Restaurant Reservation System for "CHEESE AND TOAST RESTO." It allows users to book tables, view available seats, and manage reservations.

Features:
Menu Section: Displays four dishes with descriptions.
Reservation Form: Users can enter their name, phone, and number of guests to reserve a table.
Seats Availability: Shows the number of available seats (starts at 10).
Reservation List: Displays current reservations with options to check out or delete them.
Functionality:
Reservations decrease seat count, and checked-out or deleted reservations free up seats.
Ensures no duplicate bookings and handles guest limits.
The page is designed with a clean, user-friendly layout and responsive design.
